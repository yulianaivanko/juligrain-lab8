# JuliGrain

Навчальний лендинг салону краси у Львові. Основа проєкту — сайт із лабораторної роботи № 7.

## Що є на сайті

Послуги та ціни, мобільне меню, відео про догляд за волоссям, карта та погода. Демонстраційний запис працює в браузері й не надсилає дані.

## Локальний запуск

Запустіть Live Server у VS Code або виконайте python -m http.server 8000 і відкрийте http://localhost:8000/. Для карти, YouTube і погоди потрібен інтернет.

## Публікація

У GitHub відкрийте Settings → Pages, виберіть Deploy from a branch, гілку main і папку / (root).
