# JuliGrain

Навчальний лендинг салону краси у Львові. Основа проєкту — сайт із лабораторної роботи № 7.

## Що є на сайті

Послуги та ціни, мобільне меню, відео про догляд за волоссям, карта та погода. Демонстраційний запис працює в браузері й не надсилає дані.

## Форма зворотного зв'язку (ЛР № 9)

Секція `#contact` містить адаптивну форму: ім'я, email, телефон, тема, повідомлення та згода з політикою конфіденційності.

- `assets/js/validation.js` — клієнтська валідація на Vanilla JS (RegEx для email, телефону `+380XXXXXXXXX` та імені), динамічна перевірка на `input`/`blur`, повна перевірка на `submit`.
- `assets/css/styles.css` — анімація модального вікна та галочка успішного стану; решта стилів — Tailwind-класи.
- `privacy.html` — сторінка політики конфіденційності.

Бекенду немає: після успішної перевірки форма очищується й показує модальне вікно «Демонстрація успішного надсилання». Дані нікуди не передаються.

## Локальний запуск

Запустіть Live Server у VS Code або виконайте python -m http.server 8000 і відкрийте http://localhost:8000/. Для карти, YouTube і погоди потрібен інтернет.

## Публікація

[Відкрити JuliGrain на GitHub Pages](https://yulianaivanko.github.io/juligrain-lab8/)

1. У GitHub відкрийте Settings → Pages, виберіть Deploy from a branch, гілку main і папку / (root).
2. У Vercel натисніть Add New → Project, імпортуйте репозиторій, залиште Framework Preset «Other» і Root Directory «./», натисніть Deploy. Кожен push у main оновлює сайт автоматично.
3. У Netlify імпортуйте репозиторій із GitHub, виберіть main і каталог публікації ".". Збірка не потрібна.
