# JuliGrain

Сайт студії краси JuliGrain у Львові (вул. Стрийська, 45г, офіс 180/1): послуги й ціни, онлайн-запис із розрахунком вартості, галерея робіт, відгуки, карта й форма зворотного зв'язку.

Сайт: https://juligrain-lab9.vercel.app/

## Розділи

- **Послуги та ціни** (`#services`) — картки напрямів з фільтрами; прайс кожного напряму відкривається в модальному вікні (`<dialog>`, `js/app.js`).
- **Онлайн-запис і вартість** (`#calculator`, `js/widget.js`) — гостя додає кілька послуг, обирає бажану дату й час і бачить загальну вартість та орієнтовний час. Ціни й тривалість калькулятор бере прямо з прайсу на сторінці, тому вони завжди однакові. Можна оформити візит як подарунковий сертифікат. Кнопка «Записатися» відкриває вікно, де гостя вказує ім'я й телефон і підтверджує запис.
- **Галерея робіт** (Fancybox) і **відгуки** (Swiper), ефект друку в hero (Typed.js) — `assets/js/plugins.js`.
- **Форма зворотного зв'язку** (`#contact`, `assets/js/validation.js`) — перевіряє ім'я, email, телефон `+380XXXXXXXXX` і повідомлення. Після надсилання форма очищується й показує вікно подяки.
- `privacy.html` — політика конфіденційності.

## Технології

HTML, Tailwind CSS (зібраний у `css/site.min.css`), Vanilla JavaScript (`*.min.js`), Swiper, Fancybox і Typed.js з jsDelivr.

## Локальний запуск

```
python -m http.server 8000
```

і відкрийте http://localhost:8000/. Для карти, YouTube і погоди потрібен інтернет.

## Публікація

Кожен push у `main` запускає GitHub Actions (`.github/workflows/deploy.yml`): перевірка JS, Lighthouse CI (`lighthouserc.json`), потім деплой на Vercel.
